# java-racingcar-precourse

## 개요
자동차 경주 게임을 구현한다.

## 기능 요구 사항
1. 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다. (랜덤)
2. 각 자동차에 이름을 부여할 수 있다. 
3. 시작 전, 사용자가 ,(쉼표)로 자동차 이름을 입력한다.
4. 이름은 5자 이하만 가능하다.
5. 사용자는 이동 횟수를 입력할 수 있어야 한다.
6. 전진 조건은 0 ~ 9 사이 무작위 값을 구한 후, 무작위 값이 4 이상 일 경우이다.
7. 게임 완료 후, 우승자를 알려준다. (우승자는 한 명 이상일 수 있다)
8. 우승자가 여러 명일 경우 ,(쉼표)로 구분하여 알려준다.
9. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료된다.

## 예외 사항
입력값이 아래 조건을 위반할 경우 IllegalArgumentException을 발생시킨다.

1. 자동차 이름이 5자를 초과하는 경우
2. 자동차 이름 입력 전체가 비어 있거나 공백만 입력된 경우
3. 시도 횟수 입력이 숫자가 아닌 경우 (예: "a", "one")
4. 시도 횟수 입력이 0 이하인 경우 (예: 0, -3)
5. Randoms.pickNumberInRange(0, 9) 호출 결과가 0~9 범위를 벗어나는 경우

## 테스트 사항
1. 두 명 중 한 명이 승리했을 경우 정상 동작 테스트
2. 두 명 중 두 명이 같은 전진을 했을 경우 공동 우승 정상 동작 테스트
3. 자동차 이름이 5자 초과일 때 예외 발생 테스트
4. 자동차 이름을 공백으로 했을 때 예외 발생 테스트
5. 시도 횟수에 숫자가 아닌 문자열 입력 시 예외 발생 테스트
6. 시도 횟수에 정수가 아닌 수 입력 시 예외 발생 테스트
7. 시도 횟수에 양의 정수가 아닌 음의 정수 입력 시 예외 발생 테스트
