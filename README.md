# java-racingcar-precourse

## 개요
자동차 경주 게임을 구현한다.

## 기능 요구 사항
1. 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다. (랜덤)
2. 각 자동차에 이름을 부여할 수 있다. 
3. 시작 전, 사용자가 ,(쉼표)로 자동차 이름을 입력한다.
4. 이름은 5자 이하만 가능하다.
5. 사용자는 이동 횟수를 입력할 수 있어야 한다.
6. 전진 조건은 0 ~ 9 사이 무작위 값을 구한 후, 무작위 값이 4 이상 일 경우이다.
7. 게임 완료 후, 우승자를 알려준다. (우승자는 한 명 이상일 수 있다)
8. 우승자가 여러 명일 경우 ,(쉼표)로 구분하여 알려준다.
9. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료된다.
